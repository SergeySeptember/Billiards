# Billiards - Match Timer & Stats

Приложение для ведения счета в русском бильярде и сохранения статистики матчей.

Проект написан на **.NET 10** и собран как **Android-only** приложение на **.NET MAUI**. Под iOS, Windows и другие платформы проект не поддерживается.

## Данные и хранение

### Локальная база

Используется SQLite. Хранятся:
- игроки
- матчи
- агрегированная статистика, вычисляемая на основе матчей

### Бэкап и восстановление

- Экспортирует все данные в один JSON-файл
- Импорт выполняет полное восстановление с заменой текущих данных

## Звуки

Если звуки включены в настройках, приложение проигрывает подготовленные аудиоэффекты и фразы.

Файлы лежат в `Billiards/Resources/Raw/`.

Для части кнопок используются не одиночные звуки, а случайный выбор из набора:
- старт партии
- увеличение забитых шаров
- увеличение дураков
- увеличение штрафов

## Платформа и ограничения

- Проект таргетит только `net10.0-android`
- Минимальная версия Android для устройства: **Android 10 / API 29**
- Для локальной сборки под `.NET 10` нужен установленный Android SDK Platform **API 36**
- UI подгонялся в первую очередь под **Google Pixel 10**

На других Android-устройствах приложение тоже может работать, но визуально лучше всего проверять его на экранах, близких к Pixel 10.

## Запуск и сборка

### Требования

- Visual Studio 2022 с workload `.NET MAUI`
- `.NET 10 SDK`
- Android SDK Platform `36`
- Android-эмулятор или физическое Android-устройство

### Локальный запуск

1. Откройте solution в Visual Studio.
2. Выберите Android-устройство или эмулятор.
3. Запустите проект `Billiards`.

### Публикация APK

1. Нажмите правой кнопкой на проект и выберите `Publish`
2. Дождитесь окончания архивирования и нажмите `Distribute`
3. Выберите `Ad Hoc`
4. Подпишите APK существующим ключом или создайте новый
5. Сохраните итоговый APK
